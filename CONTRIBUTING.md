# Contributing

Dupin is licensed under [GPL-3.0-or-later](./LICENSE).

Before your first pull request can be merged, sign the [Contributor License Agreement](./CLA.md) once by commenting on the pull request:

```text
I have read the CLA Document and I hereby sign the CLA
```

The CLA lets the project offer Dupin under other terms as well as the GPL; you keep the copyright in your work. A bot checks the signature and records it.

Borrowing an idea or an algorithm from another project is fine. Copying its code or data is not, unless its licence is compatible with GPL-3.0-or-later and the copy is recorded for the app's third-party notices; see [Third-party code and data](./docs/development.md#third-party-code-and-data).

Setting up, building, formatting and testing are in [docs/development.md](./docs/development.md).
