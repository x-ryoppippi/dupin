# Send to

Send to… hands the selected result to another feature or app.

## Open it

Choose **Send to…** on a result's action screen (<kbd>→</kbd>, <kbd>⌘K</kbd> or <kbd>⌃K</kbd>).

## What you can do

| Result         | What it offers                                                                  |
| -------------- | ------------------------------------------------------------------------------- |
| Text           | Copy the value, or look it up with a configured [web search](./web-searches.md) |
| Dictionary     | The same, for the definition                                                    |
| Calculator     | The same, for the copyable number                                               |
| Files and apps | The macOS share sheet, AirDrop, Mail attachments and Copy path                  |
