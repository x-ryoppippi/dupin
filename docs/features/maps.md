# Maps

Search Apple Maps for an address or place from the panel.

## Open it

Type `maps` <kbd>Space</kbd> and a place, such as `maps baker street`.

## What you can do

| Key / action                          | What it does                 |
| ------------------------------------- | ---------------------------- |
| <kbd>↩</kbd> on the Apple Maps result | Search for the place in Maps |

## Notes

- The Apple Maps keyword needs a search term, so typing just `maps` still finds the Maps app.

## Configuration

`maps` is a [web search](./web-searches.md#configuration).
